## Cara Menjalankan Notebook

1. Buka notebook yang ingin dijalankan.
2. Pilih tombol **Open in Colab** atau unggah notebook ke Google Colab.
3. Pilih **Runtime → Restart session and run all**.
4. Tunggu sampai semua sel selesai dijalankan.
5. Pastikan tidak terdapat error dan semua visualisasi muncul.
